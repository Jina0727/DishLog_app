# Dishlog

찍으면 끝나는 식단일기. iOS '밀로그'의 흐름을 안드로이드로 옮기고, 사진 칼로리 추정을 더한 개인용 앱.

## 기능
- **바로 촬영**: 앱을 열면 카메라부터 켜져요 (설정에서 끌 수 있음). 반찬이 따로면 여러 장 찍어 한 끼로 묶어요.
- **식사 구간 태그**: 설정에서 구간을 정하면(예: 점심 13:00–15:00) 그 시간에 찍은 사진에 태그가 자동으로 붙어요. 구간 밖 사진은 태그 없이 저장하거나 가까운 구간으로 붙일 수 있어요.
- **기록 편집**: 카드를 눌러 태그·시간·먹은 양·포만도(3단계)·메모를 고쳐요.
- **칼로리 추정**: 사진을 비전 모델(Claude)에 보내 음식별 칼로리를 추정해요. 여러 장이면 겹친 음식은 한 번만 세요.
- **지난 날짜 모아보기**: 사진만 크게 모아 보거나 카드 목록으로 봐요.
- **월간 달력**: 기록 있는 날만 점으로 표시.
- **홈 화면 위젯 (1×1 '기록')**: 누르면 앱 전체가 아니라 촬영 창만 홈 화면 위로 떠요. 한 장 찍으면 저장하고 닫혀요. 앱 아이콘을 길게 눌러 '바로 찍기'로도 열 수 있어요.

## 빌드 (PC 없이)
`main` 에 푸시하면 GitHub Actions 가 APK 를 빌드해서 **Releases > latest** 에 `Dishlog.apk` 로 올려요.
폰 브라우저로 저장소의 Releases 에 들어가 받으면 돼요. (처음 설치할 때 '출처를 알 수 없는 앱' 허용 필요)

## 칼로리 추정 켜기
저장소 **Settings > Secrets and variables > Actions > New repository secret**
- 이름: `ANTHROPIC_API_KEY`
- 값: Anthropic API 키

키가 없으면 칼로리 추정만 꺼진 채로 나머지는 그대로 동작해요.
키는 APK 안에 들어가므로 개인용으로만 쓰세요. 다른 사람에게 배포하려면 서버를 거쳐 호출하도록 바꿔야 해요.
