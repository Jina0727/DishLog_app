# Dishlog

찍으면 끝나는 식단일기. iOS '밀로그'의 흐름을 안드로이드로 옮기고, 사진 칼로리 추정을 더한 개인용 앱.

## 설치
**[Dishlog.apk 받기](https://github.com/Jina0727/DishLog_app/releases/download/latest/Dishlog.apk)**

폰 브라우저(Chrome·삼성 인터넷)로 받아 설치하세요. 처음 설치할 때는 '출처를 알 수 없는 앱' 허용이 필요해요.
새 버전은 같은 링크에서 받아 덮어 설치하면 기록이 그대로 유지돼요.

## 기능
- **바로 촬영**: 앱을 열면 카메라부터 켜져요 (설정에서 끌 수 있음). 사진은 정사각형으로 저장되고, 반찬이 따로면 여러 장 찍어 한 끼로 묶어요.
- **식사 구간 태그**: 설정에서 구간을 정하면(예: 점심 13:00–15:00) 그 시간에 찍은 사진에 태그가 자동으로 붙어요. 구간마다 색·아이콘을 고를 수 있어요.
- **하루 타임라인**: 홈에서 시간 축을 따라 그날 기록이 이어져요. 좌우로 넘기면 전날·다음날, 위에서 당기면 월간 달력이 펼쳐져요.
- **기록 상세·수정**: 카드를 누르면 사진·칼로리·포만도·메모, 길게 누르면 수정·삭제.
- **칼로리 추정**: 사진을 Claude에 보내 음식별 칼로리를 추정해요. 포장 제품은 영양성분표를 우선으로 읽고, 우유에 타 먹는 식으로 더해지는 재료도 따로 계산해요. "밥은 반 공기만 먹음" 같은 메모를 함께 보낼 수 있어요.
- **홈 화면 위젯 (3×1 ~ 5×1)**: 오늘 찍은 사진·추정 칼로리와 찍기 버튼. 누르면 앱 전체가 아니라 촬영 창만 떠서, 찍으면 칼로리까지 보여주고 닫혀요. 앱 아이콘을 길게 눌러 '바로 찍기'로도 열 수 있어요.

## 칼로리 추정 켜기
1. [console.anthropic.com](https://console.anthropic.com) 에서 API 키를 만들어요 (크레딧 충전 필요).
2. 앱 **설정 → 칼로리 추정 (Claude) → API 키**에 붙여넣으면, 키가 유효한지 확인한 뒤 저장돼요.

키는 폰 안(앱 전용 저장소)에만 저장되고 APK나 저장소엔 들어가지 않아요.

## 빌드
`main` 에 푸시하면 GitHub Actions 가 APK 를 빌드해서 **Releases > latest** 에 `Dishlog.apk` 로 올려요.
빌드가 실패하면 컴파일 에러가 Actions 실행 화면에 주석으로 표시돼요.

로컬에서 빌드하려면 Android Studio 로 열거나 `gradle :app:assembleDebug` (JDK 17, Gradle 8.11).
`app/debug.keystore` 는 업데이트 설치가 막히지 않도록 고정해 둔 개인용 디버그 서명 키예요.
